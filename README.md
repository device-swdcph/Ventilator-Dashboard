# Ventilator PM Battery Dashboard

แดชบอร์ดสถานะเครื่องช่วยหายใจและผลทดสอบแบตเตอรี่ ดึงข้อมูลสดจาก Google Sheet
`(Dashbopard) เครื่องช่วยหายใจ PM Batery` ผ่าน Google Visualization API (gviz) — ไม่ต้องมี API key

## การตั้งค่า

1. **แชร์ Google Sheet** → "ทุกคนที่มีลิงก์" สิทธิ์ "ผู้มีสิทธิ์อ่าน" (จำเป็น ไม่เช่นนั้นดึงข้อมูลไม่ได้)
2. **เปิด GitHub Pages**: Settings → Pages → Source: *Deploy from a branch* → Branch `main` / `(root)`
   จะได้ URL: `https://device-swdcph.github.io/Ventilator-Dashboard/`
3. **ฝังใน Google Sites**: แทรก → ฝัง (Embed) → แท็บ "ตาม URL" → วาง URL ข้างบน → ปรับขนาดกรอบ

## โครงสร้างข้อมูลที่อ่าน (sheet gid=0, คอลัมน์ A–J)

| คอลัมน์ | ข้อมูล |
|---|---|
| A | ลำดับ |
| B | ชื่อรุ่น |
| C | วันที่รับเข้า |
| D | อายุการใช้งาน (ปี) |
| E | หมายเลขครุภัณฑ์ |
| G | สถานะการทดสอบแบต (ผ่าน / แบตเตอรี่เสื่อม / ตรวจสอบไม่ได้/ชำรุด) |
| H | หมายเหตุ/ชำรุด |
| I | การใช้งาน (ใช้งานได้ / ใช้งานไม่ได้) |
| J | วันที่ตรวจ (แสดงเป็น "ข้อมูล ณ วันที่") |

ตารางสรุปคอลัมน์ L–M ไม่ถูกใช้ — แดชบอร์ดคำนวณสรุปเองจากรายการเครื่อง
หน้าเว็บรีเฟรชข้อมูลอัตโนมัติทุก 5 นาที (แก้ได้ที่ `AUTO_REFRESH_MS` ใน `index.html`)
